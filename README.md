# まちの朝市

HTMLとCSSの基礎学習として作成した、架空の朝市を紹介する1ページのWebサイトです。

公開ページ: https://j0in021.github.io/machi-no-asaichi/

デザイン見本と仕様書はAIが作成しました。その見本と仕様書を確認しながら、HTMLの構造からCSSのレイアウト、スマートフォン表示まで自分で実装しました。分からない部分はAIに質問して仕組みを確認し、表示を確かめながら修正しています。

## 学習したこと

- HTMLによる見出し、文章、リンク、画像の構造化
- Flexboxを使った横並び
- CSS Gridを使ったカードの3列配置
- メディアクエリによるスマートフォン表示
- `position: relative`と`position: absolute`を使った画像配置
- `margin`、`padding`、`gap`による余白調整
- ページ内リンクとキーボードフォーカスの確認

## 表示の切り替え

- PC表示：出店カードを3列で表示
- 375px以下：出店カードを1列で表示
- スマートフォンでは、導入画像を右下に配置

## 使用技術

- HTML
- CSS

JavaScriptやCSSフレームワークは使用していません。

## 確認したこと

- 1200px、375px、中間幅での表示
- ページ内リンク
- 長い店名の折り返し
- 画像が読み込めない場合の文章表示
- Tabキーによるリンク移動とフォーカス表示

## ページについて

掲載している朝市、店舗名、開催場所は学習用の架空の内容です。
